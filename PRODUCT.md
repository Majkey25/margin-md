# Margin

Chrome extension for local Markdown files. Open, edit, preview, save.

* Full extension tab. Source, split, preview views.
* Local picker and file drop. Manual Save and Save As.
* Guard unsaved changes. Block active Markdown HTML and remote resources.
* Work offline. No account, server, telemetry, or document upload.
* Calm modern UI. Czech copy. Desktop split view; mobile single pane.

Defaults inferred from the brief: private GitHub repository `margin-md`, light theme, one document at a time. Opus owns visual design. Installation is unpacked; Chrome Web Store publication is outside scope.
